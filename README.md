### 2. Gamification: ไดโนเสาร์เติบโตตามแต้ม (5 Evolution Stages)
ทุกๆ แต้มที่สมาชิกสะสม จะส่งผลต่อวิวัฒนาการของสัตว์เลี้ยงประจำตัว:
1. **🥚 ระยะไข่ (Egg Stage: 0-99 แต้ม):** ไข่ลายจุดฟองโต ขยับดุ๊กดิ๊กไปมา เมื่อแตะจะสั่นไหวและมีเสียง Pop
2. **✨ ระยะฟักไข่ (Hatching Stage: 100-249 แต้ม):** เปลือกไข่เริ่มแตกร้าว มีประกายแสงสีทองเรืองรอง
3. **🐣 ระยะแรกเกิด (Baby Stage: 250-499 แต้ม):** เบบี้ไดโนเสาร์ตัวจิ๋ว ตาโตแป๋ว กระพริบตาและขยับตัวร่าเริง
4. **🦖 ระยะกำลังโต (Growing Stage: 500-999 แต้ม):** ไดโนเสาร์วัยกำลังโต ร่างกายแข็งแรง แตะแล้วกระโดด แสดงหัวใจ และส่งเสียงคำรามสดใส
5. **🏆 ระยะโตเต็มวัย (Adult Stage: 1,000+ แต้ม):** "ด็อกเตอร์ไดโนเสาร์ NSM" สวมชุดกาวน์วิจัย แว่นตาทดลอง พร้อมเอฟเฟกต์พลุเฉลิมฉลอง

### 3. ระบบภารกิจสะสมแต้ม (Quest & Mission System)
- แอดมินสามารถเพิ่ม/ลบ/แก้ไขภารกิจของพิพิธภัณฑ์ได้
- สมาชิกสามารถทำภารกิจแบบโต้ตอบ เช่น **ตอบคำถามวิทยาศาสตร์ประจำวัน (Daily Science Quiz)** เพื่อรับแต้มทันที หรือเช็คอินจุดชมนิทรรศการ
- ระบบเสียงสังเคราะห์ในตัว (Web Audio API Synthesizer) ไม่ต้องโหลดไฟล์เสียงภายนอก โหลดไว ไม่ติดปัญหาเรื่องลิขสิทธิ์

### 4. เชื่อมต่อ Google Sheets แบบ Real-time
- รองรับทั้งการวางลิงก์ Google Sheets แบบปกติ, CSV Export URL และ Google Apps Script Web App
- มีระบบดึงข้อมูลอัตโนมัติผ่าน Server Proxy ป้องกันปัญหา CORS
- มีปุ่ม Export รายชื่อสมาชิกเป็น CSV และมีเทมเพลต Google Apps Script สำหรับซิงค์สองทางในตัว

### 5. แผงควบคุมแอดมิน (Admin Dashboard & UX/UI Customizer)
- ตารางค้นหา, กรองตามระยะไดโนเสาร์, เพิ่ม, แก้ไข, ลบสมาชิก
- ตัวปรับแต้มด่วน (+10, +30, +50, +100, -20, -50) พร้อมเลือกเหตุผลจากรายการภารกิจ
- ปรับเปลี่ยนธีมสี (ฟ้าสดใส, ฟ้าคราม, น้ำเงินวิทย์, มรกต, ส้มอำพัน)
- ปรับเปลี่ยนข้อความแถบประกาศหัวเว็บ (Announcement Banner)
- ปรับเกณฑ์คะแนนวิวัฒนาการไดโนเสาร์ทั้ง 5 ระยะได้อย่างอิสระ

## 🚀 สถาปัตยกรรมและเทคโนโลยี (Tech Stack)

- **Frontend & Backend:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (Custom theme: Sky Blue NSM)
- **Icons:** Lucide React
- **Celebration Effects:** Canvas Confetti
- **Audio Engine:** HTML5 Web Audio API

## ☁️ การนำขึ้น Vercel (Vercel Deployment)

1. นำโค้ดขึ้น GitHub Repository:
   ```bash
   git remote add origin https://github.com/nutchayaploy/nsm1.git
   git branch -M main
   git push -u origin main
   ```
2. ไปที่ [vercel.com](https://vercel.com)
3. กด **"Add New Project"** -> เลือก Repository `nutchayaploy/nsm1`
4. กด **"Deploy"** ระบบจะ Build และเปิดให้บริการทันทีโดยไม่ต้องตั้งค่าเพิ่มเติม!
